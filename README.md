# Stopwatch
With start, stop, resume, reset features; It is also a program that you can record laps and print out as a text document. It supports both English and Turkish languages.
## Changelogs
### v2
 - The app has been rebuilt.
 - The design of the application has been renewed. You can choose 3 different themes: Default, Light, Dark
 - The language selection feature has been removed. But don't worry about it. Now the application detects the language of your operating system and the language support of the program is adjusted accordingly.
 - After that, you will be able to maximize the window of the Stopwatch application.
### v1.1
 - You can now choose which folder to save the text documents in.
### v1.0
 - Initial release.
